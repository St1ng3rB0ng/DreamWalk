# DreamWalk
Web-based travel manager for routes, trips, and companions.

## Overview
DreamWalk is a web application that helps users discover travel routes, 
explore new places, and connect with others for shared trips or casual walks.  

It combines trip planning with social interaction — making travel more personal, engaging, and collaborative.

## Features
- Browse and filter routes, destinations, and events  
- View descriptions, schedules, and estimated costs  
- Find companions for shared travel or local walks  
- Save favorite places and manage planned trips  
- Admin and moderator tools for managing content and users  

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Java   
- **Database:** PostgreSQL  
- **Version Control:** Git + GitHub  
- **Management:** Jira

## Branching Model
- main – stable production-ready branch  
- dev – main development branch  
- feature – new feature implementation
